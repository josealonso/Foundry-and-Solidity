# Foundry-and-Solidity
Learning intermediate Solidity concepts using Foundry (no more Hardhat)

## Installing Foundry

```bash
curl -L https://foundry.paradigm.xyz | bash
```

then 

```bash
foundryup
```

installs  install the complete Foundry suite 
- **forge**
- **cast**
- **anvil**
- **chisel**

```bash
$ forge --version
```
